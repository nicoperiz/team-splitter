# Team Splitter

A web application that splits players into balanced teams based on skill level.

## 🚀 Live Demo
[https://nicoperiz.github.io/team-splitter/](https://nicoperiz.github.io/team-splitter/)

## ✨ Features
- Add players with name and skill level (Strong, Medium, Weak)
- Balanced team distribution using round-robin sorting by skill
- Strength score per team with visual progress bar
- Remove individual players
- Reset everything in one click
- Enter key support

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, CSS Grid)
- Vanilla JavaScript (ES6+)
