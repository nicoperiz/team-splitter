# Team Splitter

## What it does

Team Splitter is a simple web application that helps you divide players into balanced teams based on their skill levels. You can add players with names and assign them skill levels (Strong, Medium, Weak), then split them into a specified number of teams. The app ensures balanced teams by distributing players in a round-robin fashion after sorting them by skill level.

## Features
- Add players with custom names and skill levels (Strong, Medium, Weak)
- Remove individual players from the list
- Split players into 2 or more teams
- Reset the entire player list and teams
- Keyboard shortcuts: Press Enter in the player name field to add, or in the number of teams field to split
- Responsive design with a clean, dark theme

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
